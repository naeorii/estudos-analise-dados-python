# estudos-analise-dados-python

Repositório criado para registrar meu progresso no curso **Data Analysis with Python** do FreeCodeCamp, com exercícios e exemplos desenvolvidos em Python e Jupyter Notebook.

## Conteúdos estudados

* Introdução à análise de dados
* Exemplos práticos de análise
* Utilização do Jupyter Notebook
* Criação e organização de células
* Importação e exportação de dados
* Introdução ao NumPy
* Criação e manipulação de arrays
* Operações matemáticas com NumPy
* Filtros e arrays booleanos
* Álgebra e dimensões de arrays
* Introdução ao Pandas
* Indexação e seleção condicional
* Criação e modificação de DataFrames
* Criação de novas colunas
* Limpeza de dados
* Remoção de dados duplicados
* Visualização de dados
* Leitura de arquivos CSV e TXT
* Leitura de dados de bancos de dados
* Extração de dados de páginas HTML
* Funções, coleções, repetições e módulos em Python

## Tecnologias utilizadas

* Python
* NumPy
* Pandas
* Jupyter Notebook
* Google Colab
* Git e GitHub

## Objetivo

Desenvolver conhecimentos em análise, manipulação, limpeza e visualização de dados utilizando Python.
